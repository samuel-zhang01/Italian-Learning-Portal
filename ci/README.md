# Trusted-main local app checks

Main pushes and explicit main dispatches use only `ci-italian`, with exact repository/ref/event gating before checkout and no hosted fallback. There was no prior workflow or PR trigger; none is invented for PRs. The dedicated listener must have no default labels, with external-contributor approval tightened before it comes online. Labels are routing, not cross-repository isolation on the shared Unix/Docker host.

The worker runs the maintained `npm run lint`, `npm run typecheck`, `npm run build:daily` and `npm run test:daily` commands, attempting all four and refusing any nonzero result. The daily tests cover learning, academy, arcade, answer contracts, the book course, local PDFs, media/caption import contracts, discovery, chapter continuity, compact planning metadata, the review queue, source-backed supplements, A2 topic checks, weekly evidence, local listening, progress merging, public-only offline caching, release discovery and saved short listening/speaking practice. TAP accounting requires at least 252 actual non-skipped passing tests. The pinned build command regenerates planning metadata; the pinned test command verifies freshness. The source-preservation check requires regenerated metadata to remain byte-identical to the committed file. The build must produce the public daily site in `site-dist/`, with HTML, CSS, JavaScript, the favicon, install manifest, offline worker and optional WebP artwork, and no unexpected file types. These checks do not replace browser journeys or real learner observation. Legacy Vinext commands remain available locally but are not the deployment build gate.

A pinned AMD64 Node 22.22.2 dependency image receives only package.json/package-lock.json and CI build support. `npm ci --ignore-scripts --include=dev` uses the exact integrity-bound public npm tarballs, separate empty user/global config locations and strict HTTPS registry settings. No owner environment or credentials are supplied. Python 3 is included only for the stdlib CI wrapper. Networked preparation has a 1200-second timeout and the shared Docker-daemon resource boundary, not the test cgroup. Fresh preflight requires load below 6, available RAM at least 8 GiB, runner free space at least 15 GiB and actual Docker-storage free space at least 20 GiB. First native dependency/build compatibility is still to be established.

The check container is nonroot UID/GID 10001 with read-only root/input, network none, capabilities zero, no-new-privileges/default seccomp, 1 CPU, 4 GiB without swap and 512 tasks. Effective kernel/cgroup state is checked. The complete tracked input is copied into a private bounded 2 GiB noexec tmpfs; node_modules is an image-owned read-only dependency tree. Only its exact `.vite-temp` config-bundler cache gets a separate fresh bounded 64 MiB noexec tmpfs. Native esbuild/workerd packages execute from the image, not the noexec source copy. No old mount policy or app command is changed.

The static daily build uses `vite.static.config.ts` and does not need Wrangler, Miniflare or D1. Tests read committed curriculum/code and synthetic progress, not the learner database. No `.wrangler`, ignored `.env`, learner backup, owner Git config, API key or existing SQLite data is exported. Paid AI and telemetry are disabled; network none prevents provider traffic. The local launcher, migrations and dev/start/deploy commands are never invoked. No D1 recovery, real provider, browser or existing local-hosting acceptance is inferred.

Per-repository/run/attempt/mode/operation labels and names are tracked before creation. Exact ownership is inspected, removal uses full IDs, post-removal name/ID absence is required, and other cleanup continues on error. A workflow `always()` step reconciles only this job's scope. Unknown build/create completion or cleanup failure retains the private journal and refuses acceptance. No shared image/cache prune or service operation is used. The owner’s existing local app and learner state remain untouched; this does not establish isolation from the shared host’s root-equivalent CI authority.
